Google Sheets Connection Guide

1

Create your Google Sheet

Go to sheets.new to create a blank spreadsheet.

In the first row (Row 1), type these exact column headers (they must match perfectly):

Timestamp firstName lastName email phone ticketType dietary comments registrationStatus virtualOption futureEvents
2

Add the Google Apps Script

  1. In your Google Sheet, click Extensions > Apps Script.
  2. Delete any existing code in the editor that appears.
  3. Copy and paste the entire block of code below:
const sheetName = 'Sheet1'; // Make sure this matches your sheet tab name

function doPost(e) {
  try {
    const doc = SpreadsheetApp.getActiveSpreadsheet();
    const sheet = doc.getSheetByName(sheetName);
    const headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0];
    
    // Create new row data based on form submission
    const newRow = headers.map(function(header) {
      if (header === 'Timestamp') {
        return new Date();
      }
      // Return the form value matching the header name, or empty string if not found
      return e.parameter[header] || ''; 
    });

    // Append to sheet
    sheet.getRange(sheet.getLastRow() + 1, 1, 1, newRow.length).setValues([newRow]);

    // Return success response to the webpage
    return ContentService
      .createTextOutput(JSON.stringify({ 'result': 'success' }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    // Return error response
    return ContentService
      .createTextOutput(JSON.stringify({ 'result': 'error', 'error': error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
3

Deploy as Web App

  1. In the Apps Script editor, click the blue Deploy button (top right), then select New deployment.
  2. Click the gear icon ⚙️ next to "Select type" and choose Web app.
  3. Under Execute as, select "Me".
  4. Under Who has access, select "Anyone" (Crucial step!).
  5. Click Deploy. (You will need to authorize access. Click 'Review permissions', choose your Google account, click 'Advanced', and then 'Go to Untitled project (unsafe)').
  6. Copy the Web app URL provided on the final screen.
4

Connect the Code

Open the HTML code of this application in any text editor. Scroll down to the Javascript section (around line 400) and find the variable GOOGLE_SCRIPT_URL. Paste your Web App URL there.

// Change this line in the Javascript code:
const GOOGLE_SCRIPT_URL = "PASTE_YOUR_COPIED_URL_HERE";
